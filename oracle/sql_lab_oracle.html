🗂️ Como acessar as tabelas do HR no Oracle?

Na VM da aula, use o SQL*Plus para consultar o schema HR. Teste SELECT * FROM HR.EMPLOYEES;. Se funcionar, você pode usar ALTER SESSION SET CURRENT_SCHEMA = HR; para consultar as tabelas sem o prefixo HR. Não execute comandos de alteração nos dados.
